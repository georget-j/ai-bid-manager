# Market Wedge Product Requirements v3

## Product north star

A secure, UK-specific bid operating system that helps bid agencies and SME suppliers turn public-sector opportunities into evidence-backed, reviewable, submission-ready bid packs.

## Primary users

### Agency owner

Needs:

- manage client workspaces
- view deadlines
- assign work
- monitor reviews
- export client-ready packs

### Bid writer

Needs:

- analyse tenders
- generate matrices
- draft answers
- request evidence
- edit responses

### Reviewer

Needs:

- review flagged answers
- approve/reject/edit
- check citations
- comment on risk

### Client user

Needs:

- upload requested evidence
- approve company facts
- review drafts
- view readiness

### Admin

Needs:

- manage users
- manage sources
- monitor sync
- monitor AI usage
- audit logs

## Critical workflows

### Client onboarding

1. Create client workspace.
2. Complete client profile.
3. Select vertical.
4. Upload evidence documents.
5. Generate readiness score.
6. Show missing evidence.

### Opportunity qualification

1. Add opportunity.
2. Attach tender documents.
3. Extract summary.
4. Score fit.
5. Score readiness.
6. Show risks.
7. Recommend bid/maybe/no-bid.
8. Add to pipeline.

### Evidence gap report

1. Analyse tender requirements.
2. Compare against evidence vault.
3. Identify strong/weak/missing evidence.
4. Create client evidence request.
5. Track request status.

### Compliance matrix

1. Upload tender docs.
2. Extract requirements.
3. Mark mandatory/pass-fail.
4. Add evidence needed.
5. Assign owners.
6. Track statuses.

### Draft response

1. Select requirement.
2. Retrieve relevant evidence.
3. Draft answer.
4. Include citations.
5. Flag unsupported claims.
6. Send risky answers to review.

### Bid pack export

1. Compile opportunity summary.
2. Add recommendation.
3. Add evidence gaps.
4. Add compliance matrix.
5. Add approved answers.
6. Add citations.
7. Add unresolved risks.
8. Export.
