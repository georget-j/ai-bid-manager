# Fortis Cyber Solutions Ltd — Service Catalogue

## Overview

This catalogue describes each service offered by Fortis Cyber Solutions Ltd, including scope, typical duration, deliverables, and indicative pricing. All pricing is exclusive of VAT. Travel and accommodation are charged at cost for engagements requiring on-site attendance beyond 50 miles of Leeds LS1.

---

## 1. Cyber Essentials (Self-Assessment)

**Description:** Fortis acts as the certifying body for the NCSC Cyber Essentials scheme. We guide the applicant through completing the online self-assessment questionnaire (SAQ) and verify the responses before issuing the certificate.

**Scope:** All devices within the defined system boundary connected to the internet.

**Deliverables:**

- Pre-assessment scoping call (30 min)
- Completed SAQ review and feedback
- Remediation advice (if required)
- CE certificate (IASME-issued, NCSC-backed) on successful completion

**Typical duration:** 5–10 working days from submission to certificate (depending on remediation needed)

**Pricing:**
| Organisation size | Price (ex VAT) |
|-------------------|----------------|
| 1–24 employees | £350 |
| 25–99 employees | £450 |
| 100–499 employees | £600 |
| 500+ employees | £850 |

**Notes:** Annual renewal required. Multi-year discount: 10% on year 2 renewal if booked at time of initial certification.

## 2. Cyber Essentials Plus (Verified Assessment)

**Description:** Building on CE self-assessment, CE+ requires Fortis to conduct an independent technical verification of the controls. This includes vulnerability scanning, configuration sampling, and firewall review.

**Scope:** Includes all CE controls plus verification of patch management, boundary firewalls, access controls, malware protection, and secure configuration via authenticated scanning and sampling.

**Deliverables:**

- System Description document (co-produced with client)
- External vulnerability scan report
- Internal authenticated vulnerability scan report
- Firewall configuration review note
- CE+ certificate (on passing) or findings report with remediation guidance (if remediation required)
- DSPT alignment notes for NHS applicants (where applicable)

**Typical duration:** 10–15 working days (simple organisations); 15–25 working days (multi-site or complex)

**Pricing:**

| 1–24 employees | £1,200 |
| 25–99 employees | £2,100 |
| 100–499 employees | £3,800 |
| 500–999 employees | £6,500 |
| 1,000+ employees | POA |

**Add-ons:**

- Remediation support: £900/day (named consultant)
- DSPT alignment pack: £1,400 flat

## 3. Infrastructure Penetration Testing

**Description:** A structured assessment of internal and/or external network infrastructure, identifying exploitable vulnerabilities and demonstrating potential attack paths. Conducted by CREST-certified testers.

**Scope options:**

- External only (internet-facing perimeter)
- Internal only (on-site or via VPN)
- Combined (external + internal)

**Methodology:** PTES (Penetration Testing Execution Standard); OWASP Testing Guide where applicable; CVSSv3.1 scoring.

**Deliverables:**

- Executive summary (board-ready, non-technical)
- Technical findings report (vulnerability detail, proof-of-concept evidence, CVSS scores)
- Remediation recommendations (prioritised)
- Retest of critical/high findings (included within 60 days)

**Typical duration:**

- External only: 3–5 days testing + 2 days reporting
- Internal only: 3–5 days testing + 2 days reporting
- Combined: 7–10 days testing + 3 days reporting

**Pricing (indicative):**
| Scope | Indicative range |
|-------|-----------------|
| External — small org (<50 IPs) | £4,500–£7,500 |
| External — medium org (50–200 IPs) | £7,500–£14,000 |
| Internal — small org | £6,000–£10,000 |
| Internal — medium org | £10,000–£18,000 |
| Combined (small/medium) | £12,000–£28,000 |

**Notes:** OT/ICS environments attract a premium. All testing is scoped via a formal Statement of Work and Rules of Engagement document.

## 5. Social Engineering Assessment

**Description:** Targeted phishing, vishing (phone-based), and physical security assessments to evaluate the human element of an organisation's security posture.

**Types:**

- Phishing simulation (email-based; bespoke pretext)

- Physical (tailgating, USB drop, visitor impersonation)

**Deliverables:** Campaign report (click rates, credential harvest rates, by department); recommended awareness interventions.
